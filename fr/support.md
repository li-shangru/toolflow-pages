# Support ToolFlow

Merci d'utiliser ToolFlow.

Si vous avez besoin d'aide avec l'application, si vous rencontrez un problème ou si vous avez des suggestions pour de nouveaux outils ou fonctionnalités, veuillez contacter le développeur.

E-mail : shangru.li@pm.me

Lors du signalement d'un problème, il peut être utile d'inclure :
- Le modèle de votre appareil
- La version iOS
- Une brève description du problème

Les suggestions de fonctionnalités sont toujours les bienvenues.
