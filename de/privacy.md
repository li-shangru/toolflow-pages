# ToolFlow Datenschutzrichtlinie

Zuletzt aktualisiert: März 2026

ToolFlow ist eine Sammlung von Offline-Dienstprogrammen für alltägliche Aufgaben.

## Datenerhebung

ToolFlow erhebt, speichert oder überträgt keine personenbezogenen Daten.

Alle Berechnungen, Konvertierungen und Tools laufen vollständig auf dem Gerät.
ToolFlow verwendet keine Analysedienste, Werbe-Frameworks oder Tracking-Technologien.

## Berechtigungen

Einige Tools können Geräteberechtigungen anfordern (z. B. Kamera, Mikrofon, NFC oder Standort), wenn die entsprechende Funktion verwendet wird.
Daten aus diesen Funktionen werden lokal auf dem Gerät verarbeitet und niemals extern übertragen.

## Drittanbieterdienste

ToolFlow gibt keine Daten an Dritte weiter und integriert keine Analyse- oder Werbe-SDKs von Drittanbietern.
